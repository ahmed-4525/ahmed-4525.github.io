# Md Ahmed Hussain — Academic Portfolio

A responsive academic portfolio website built with plain HTML, CSS and JavaScript. It is ready to publish with GitHub Pages.

## 1. Add your photograph
Place your professional portrait in `assets/` and name it exactly:

`profile.jpg`

A vertical portrait works best. The recommended image ratio is around 4:5. The page currently displays a designed placeholder until you add the image.

## 2. Add your CV
To add a downloadable CV, put your PDF in the project folder as `Ahmed_Hussain_CV.pdf` and add a link to it in the hero or navigation. The current version does not invent a CV download link because no CV file was supplied.

## 3. Publish with GitHub Pages
1. Sign in to GitHub using `ahmed-4525`.
2. Create a **public** repository named exactly `ahmed-4525.github.io`.
3. Upload all files and folders from this project (keep `index.html` at the repository root).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Your site should appear at `https://ahmed-4525.github.io/` after GitHub finishes deploying.

## 4. Before publishing — please verify
- Confirm the exact publication title, author order and bibliographic details using the DOI page.
- Confirm the wording/status of the Prime Minister's Gold Medal. The page currently says you were selected and asks you to confirm conferral status before describing it as received.
- Add your portrait and optionally your CV PDF.
- Add your ORCID, Google Scholar and ResearchGate profile URLs if you have them. The ORCID link is currently a generic placeholder and should be replaced or removed.
- Review project descriptions, dates and award details for accuracy.
- Consider adding conference presentations and a research gallery after the initial launch.

## 5. Edit the website
- `index.html`: all text and page sections.
- `styles.css`: colours, typography, layout and responsive styling.
- `script.js`: mobile navigation and current-year footer.

The site uses Google Fonts from the web; system fallback fonts are included.
